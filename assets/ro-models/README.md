# RO model photos

Put product photos for the animation here. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, and `.avif`.

Use descriptive filenames such as `domestic-ro-25-lph.jpg`, `commercial-ro-500-lph.webp`, and `industrial-ro-plant.jpg`. The filename is used to create the image's accessible alt text. Use one image per model; landscape photos work best. The Vite app picks up files in this folder automatically.
