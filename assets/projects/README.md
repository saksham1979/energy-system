# Completed project photos

Put photos of completed customer installations and projects here. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, and `.avif`.

Use descriptive filenames such as `agra-school-ro-installation.jpg` or `community-water-plant.webp`. These photos are included in the same home page animation after the RO model photos. Only use photos you have permission to publish. The Vite app picks up files in this folder automatically.
